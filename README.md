# Hyvor Talk for MODX

The Hyvor Talk extra for MODX allows you to easily integrate the Hyvor Talk comment system into your MODX website. With 
this extra, you can add comment sections, display comment counts, and manage gated content based on membership plans.

Learn more about Hyvor Talk at [https://talk.hyvor.com/](https://talk.hyvor.com/?partner=matdave).
